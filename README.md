
# Smart Restaurant Analytics & Revenue Prediction

A full-stack web application that helps restaurant owners analyze sales data and forecast future revenue.

## Features
- CSV sales data upload and validation
- Interactive sales analytics dashboard
- Product and category performance analysis
- Revenue forecasting using machine learning
- Exportable business reports

## Technology Stack
- Frontend: React + Vite
- Backend: Python + FastAPI
- Data Processing: Pandas, NumPy
- Machine Learning: scikit-learn
- Visualization: Plotly
- Version Control: Git + GitHub
