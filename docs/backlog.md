# Product Backlog

## Project

**Restaurant Intelligence Platform**

Smart Restaurant Analytics, Revenue Forecasting & Optimization.

## Product Vision

Build a professional web application that transforms restaurant sales data into useful business analytics, revenue forecasts, and transparent optimization experiments.

## Target Users

- Restaurant owners and managers
- Business analysts
- Data science learners and developers

## P0 — Core Requirements

- [ ] Define the CSV data schema.
- [ ] Define REST API endpoints and request/response formats.
- [ ] Build the React + Vite + TypeScript frontend.
- [ ] Build the Python + FastAPI backend.
- [ ] Validate uploaded CSV files.
- [ ] Calculate revenue, order count, average order value, and sales trends.
- [ ] Identify top-performing products and categories when supported by the data.

## P1 — Analytics and Machine Learning

- [ ] Implement a baseline revenue forecasting model.
- [ ] Evaluate forecasts using a chronological test set.
- [ ] Report MAE and RMSE.
- [ ] Compare Gradient Descent, Adam, and Newton's method on the same objective function.
- [ ] Visualize optimizer convergence, loss, iterations, and execution time.

## P2 — Product Quality

- [ ] Build a responsive dashboard.
- [ ] Add loading, empty, success, and error states.
- [ ] Export analytics and forecast results.
- [ ] Write backend and frontend tests.
- [ ] Add GitHub Actions for automated checks.
- [ ] Deploy the application.
- [ ] Document setup, architecture, API usage, and limitations.

## P3 — Optional Enhancements

- [ ] Add persistent database storage.
- [ ] Add authentication if time permits.
- [ ] Add evidence-based business recommendations.
- [ ] Consider Docker and PostgreSQL if the core MVP is stable.

## Definition of Done

A task is complete when:

1. The feature works as specified.
2. Relevant tests pass.
3. Errors are handled clearly.
4. Documentation is updated when necessary.
5. Changes are committed to Git.

## Constraints

- Development timeline: 15 days.
- Daily availability: approximately 1–2 hours.
- Prioritize a reliable, demonstrable MVP over unfinished advanced features.
